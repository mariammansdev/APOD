# Project Name

This project is **APOD**, which provides APOD (Astronomy Picture of the Day) features powered by NASA's API. The APOD API offers a new image or video every day, along with a brief explanation of what is being shown.

## Pages

### 1. Home Page
The home page is where you land first when you visit the project. It includes:
- A brief overview of the project, with randomly selected events displayed on the landing page to give users an immediate sense of its purpose and content..

### 2. Events Page
Provides a browsable list of all available events, allowing users to filter by date or explore randomly selected entries for quick discovery.

### 2. About Page
Offers a more detailed explanation of the project’s purpose, structure, and features, giving users deeper insight into how everything works.

### 2. Favorites Page
Displays all events that the user has marked as favorites, making it easy to revisit and manage selected items.
